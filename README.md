# Forage Midas Project

This project integrates the **Incentives API** with **Midas Core** as part of the Forage Virtual Internship.

## 🚀 Overview
The project demonstrates:
- Building and running a Spring Boot application.
- Integrating an external Incentives API service.
- Sending and receiving JSON transactions via REST endpoints.
